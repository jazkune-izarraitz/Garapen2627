# Java ariketa – alice.txt

## Zer dago hemen?

`C:/alice.txt` fitxategia irakurtzen duten bi programa:

| Fitxategia | Zer egiten du |
|---|---|
| `AlicePantailaratu.java` | Fitxategia lerroz lerro pantailaratzen du |
| `AliceIrakurri.java` | Estatistikak: lerroak, hitzak, karaktereak eta "Alice" agerpenak |

Biek **`C:/alice.txt`** bidea erabiltzen dute (Windows-en `C:\alice.txt` berdina da Javan `C:/alice.txt` idatzita).

## Nola erabili Windows-en

1. Jarri `alice.txt` fitxategia `C:\` diskoaren erroan (`C:\alice.txt`).
2. Ireki terminala karpeta honetan.
3. Konpilatu eta exekutatu:

```bat
javac AliceIrakurri.java
java AliceIrakurri
```

edo:

```bat
javac AlicePantailaratu.java
java AlicePantailaratu
```

## Proba beste bide batekin

Argumentu gisa bidea pasa dezakezu:

```bat
java AliceIrakurri C:\nire\karpeta\alice.txt
```

Enuntziatu zehatza (PDF/irudia) bidaltzen baduzu, horretara egokitu daiteke.
