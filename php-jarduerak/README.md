# Oinarrizko PHP jarduerak

Kopiatu karpeta hau XAMPP-eko `htdocs`-era, adibidez:

```text
C:\xampp\htdocs\php-jarduerak\
```

Nabigatzailean:

- Orrialde osoa (1–7): `http://localhost/php-jarduerak/oinarrizko_jarduerak.php`
- Banaka: `http://localhost/php-jarduerak/jarduera3.php` … `jarduera7.php`

PDFak orrialde bakarra eskatzen du: entregarako erabili `oinarrizko_jarduerak.php`.
