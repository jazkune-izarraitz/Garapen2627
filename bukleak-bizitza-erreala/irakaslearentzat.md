# Irakaslearentzat – gomendioak eta ohar pedagogikoak

Ikasleen orria: [ariketak.html](ariketak.html)

## Zailtasun-eskala

| Maila | Ariketak | Ideia |
|---|---|---|
| Hasiberri | A1, A2, A3, C1, B1 | Bukle bakarra, eragiketa gutxi |
| Ertaina | A4, B2, B3, B4, C2, C3, C4, D1–D3 | Kontagailuak, batura, sentinela |
| Aurreratua | D4, D5, E1–E3 | Habiaratzeak, mugak, hainbat baldintza |

## Gomendatutako buklea (D atalean «aukera librea» bada ere)

| Ariketa | Gomendioa | Zergatik |
|---|---|---|
| A1–A4 | **PARA** | Kopurua aldez aurretik ezaguna (5 egun, 4 nota, N segundo, 8 ikasle) |
| A3 | **PARA** `Con Paso -1` | Beherako kontaketa |
| B1 | **MIENTRAS** | «AMAITU» sentinela; ez dakigu zenbat liburu |
| B2 | **MIENTRAS** | Saldoa ≥ 1,20 bitartean |
| B3 | **MIENTRAS** | «bai» erantzun bitartean |
| B4 | **MIENTRAS** | 0 sentinela (landutako ariketa klasikoa, testuinguruarekin) |
| C1 | **REPETIR** | Gutxienez behin galdetu; pasahitza zuzena izan arte |
| C2 | **REPETIR** | Menua gutxienez behin; 0 aukeratu arte |
| C3–C4 | **REPETIR** | Balidazioa: tartean / >0 izan arte |
| D1 | MIENTRAS (edo REPETIR + lehen irakurketa) | «GABE» sentinela |
| D2 | PARA | 11 jokalari finko |
| D3 | MIENTRAS | Helburua lortu bitartean (80 €) |
| D4 | MIENTRAS edo REPETIR | Paperik dagoen bitartean / hurrengo eskaera |
| D5 | PARA | 1etik 20ra tarte finkoa (bakoiti/bikoiti ariketa klasikoaren bertsio laburra) |
| E1 | PARA habiaratua | Egunak × orduak |
| E2 | REPETIR + kontagailua **edo** MIENTRAS | Saiakerak ≤ 3 ETA pasahitza okerra |
| E3 | PARA habiaratua | Piramideak (PARA praktikatzeko materialaren ildoa) |

## Saioetarako proposamena

1. **Saio 1 (45–50 min):** A1, A2, A3 + B1 → PARA vs MIENTRAS kontrastea.
2. **Saio 2:** C1, C2, C3 → REPETIR noiz den egokiena (balidazioa / menua).
3. **Saio 3:** B2, B4, D2, D3 → «zein aukeratuko zenuke?» eztabaida laburra + ebazpena.
4. **Saio 4 (erronka):** E1 edo E2; nahi izanez gero E3 piramideekin lotzeko.

## Ebaluazio-irizpide azkarrak

- Buklearen aukera justifikatuta dagoen (batez ere D atalean).
- Hasierako balioak ondo jarrita (kontadorea, batura, saldoa…).
- Sentinela / irteera-baldintza zuzena.
- Kasu mugak: 0 notarik ez, saldoa zehatza, saiakera-muga…

## Oharra

Ez da beharrezkoa ariketa guztiak egitea. Aukeratu ikasleen erritmoaren arabera;
D atala bereziki baliagarria da «bukle egokia aukeratzea» landu nahi denean,
ez soilik sintaxia.
