## Helburuak

- **PARA**: errepikapen kopurua aldez aurretik ezagutzen denean
- **MIENTRAS**: baldintza hasieran egiaztatzen denean (sentinelak, balidazioa…)
- **REPETIR**: gutxienez behin egin behar denean (pasahitzak, menua…)
