🧪 Eskaneatze motak

Switch Izena Zer egiten du
-sT TCP TCP Connect Konexio osoa (3-way handshake). Root beharrik ez. Zaratatsuagoa.
-sS root SYN Stealth SYN paketea soilik; ez du handshake osatzen. Azkarragoa / “stealth”agoa. Root behar du.
-sU root UDP scan UDP atakak. Motelagoa; DNS, SNMP, DHCP… aurkitzeko.
-sN root NULL scan TCP flagik gabe. Firewall/IDS saihesteko teknikak (RFC 793).
-sF root FIN scan FIN flag soilik. Antzeko helburua: filtroak/IDS.
-sX root Xmas scan FIN + PSH + URG (paketea “argitu” egiten da). NULL/FIN bezala.
-sn Ping sweep Ostalariak aurkitu soilik; ez ataka eskaneatu. “Nork dago bizirik?”

⚙️ Switch erabilgarriak

-sV Zerbitzu/bertsio detekzioa
-O Sistema eragilea (OS) asmatu
-A Agresiboa: OS + bertsio + script + traceroute
-vv Irteera oso xehea (verbose²)
-p 22,80,443 Ataka zehatzak
-p- Ataka guztiak (1–65535)
-T5 Timing: insane (oso azkarra; zaratatsua)

Timing: -T0 … -T5 (paranoid → insane). Laborategian -T4/-T5 ohikoak.

💾 Emaitzak gorde

-oN fitx Irteera normala (gizakientzat)
-oG fitx Greppable (script/grep erraza)
-oA izena Hiru formatu: .nmap + .gnmap + .xml
nmap -sS -sV -oA txostena 10.10.12.15

Gomendioa ikasgelan: beti -oA erabili frogak/entregak gordetzeko.

📜 NSE – Nmap Scripting Engine (Lua)

Script-ak Lua-n idatzita daude. Kokapena (Linux ohikoa):

/usr/share/nmap/scripts/

Kategoria ohikoak:

auth broadcast brute default discovery dos exploit external fuzzer intrusive malware safe version vuln

Adibideak:

nmap --script=default TARGET
nmap --script=vuln TARGET
nmap --script "http*" -p 80,443 TARGET
  • -sC ≈ --script=default
  • --script=vuln: ahultasun-scriptak (kontuz, intrusive izan daiteke)
  • Script bakarra: --script=banner

🛡️ Firewall / IDS saihesteko aukerak

-Pn Ez egin host discovery (ping); tratatu ostalaria bizirik dagoela. Firewall-ek ICMP blokeatzen dutenean erabilgarria.
-f Paketeak zatitu (fragment). IDS/firewall batzuk nahas ditzake.
--scan-delay 1s Atzerapena paketeen artean; motelago = gutxiago “zaratatsu” / rate-limit saihestu.
--badsum Checksum okerra. Firewall/IDS batzuek paketea botatzen dute; erantzunik ez = filtroa.
nmap -Pn -f --scan-delay 500ms -sS TARGET

✅ Komando-txantiloiak (ikasgela)

nmap -sn 10.10.12.0/24
sudo nmap -sS -sV -vv -oA oinarria TARGET
sudo nmap -sU --top-ports 20 TARGET
nmap -Pn -p- -T4 TARGET
nmap -A -oA agresiboa TARGET
nmap --script=vuln -p 80,443 TARGET

⚠️ Root behar duten eskaneatzeak (-sS, -sU, -sN/F/X, -O…): erabili sudo. Beti baimendutako helburuetan.
