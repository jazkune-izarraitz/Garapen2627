1 Live Host Discovery

Host-ak bizirik dauden jakiteko

FlagZer egiten du
-snPing scan: host discovery bakarrik, port scanik ez
-PnHartu host guztiak online (ez egin ping)
-nDNS ebazpenik ez
-PRARP scan (sare lokalean)
-PE -PP -PMICMP echo / timestamp / address mask
-PS -PATCP SYN ping / TCP ACK ping
-PUUDP ping

ACK ping root behar du. SYN ping-ak ez du zertan.

Zure ariketa

UDP ping 53, 161 eta 162 portuetara, /30 sarean, port scanik gabe:

sudo nmap -PU53,161,162 -sn 10.200.6.0/30

UDP itxita → ICMP port unreachable = host-a up. UDP irekita → sarritan isilik.

2 Basic Port Scans

TCP flagak

SYNkonexioa hasi
ACKaitortu
RSTberrezarri
FINamaitu
PSHpush data
URGurgent

TCP Connect · -sT

Handshake osoa. Root gabe funtzionatzen du. Zarata gehiago logetan.

nmap -sT TARGET

TCP SYN · -sS

Stealth / half-open. Root behar du. Irekita: syn-ack.

sudo nmap -sS -F --reason TARGET

UDP · -sU

Motelagoa. DNS 53, SNMP 161/162, DHCP 67/68.

sudo nmap -sU TARGET

Portuak eta abiadura

-p 22,80,443portu zehatzak
-p 1-1024tartea
-Ffast: 100 portu ohikoenak
--top-ports 20N ohikoenak
--reasonzergatik open/closed

Timing · -T0 … -T5

T0Paranoid
T1Sneaky
T2Polite
T3Normal
T4Aggressive
T5Insane

-T0 = maximo isila, minimo azkarra (IDS saihesteko).

3 Advanced Port Scans

Scan mota aurreratuak

-sNNull: flagik ez
-sFFIN bakarrik
-sXXmas: FIN+PSH+URG
-sMMaimon: FIN+ACK
-sAACK: firewall mapaketa
-sWWindow scan
--scanflagsflag konbinazio propioa

Null/FIN/Xmas: closed → RST. Irekita → sarritan open|filtered.

Evasion / spoofing

-SIP iturria spoof
--spoof-macMAC spoof (LAN)
-Ddecoy IPak
-f / -ffpakete fragmentatuak
-sIIdle / zombie scan

Baimena behar da. Intrusiboak dira; laborategian bakarrik.

4 Post Port Scans · NSE

Zerbitzuak eta OS

nmap -sV --version-light TARGET
sudo nmap -O TARGET
nmap --traceroute TARGET
sudo nmap -sS -sC TARGET

-sC = default scriptak. -A = OS + version + scripts + traceroute.

Scriptak non

cd /usr/share/nmap/scripts
ls http*
ls *smb*
nmap --script-help http-robots.txt
less http-robots.txt.nse

Bidea /-rekin hasten da. ~600 script; http* 130+.

Kategoriak

defaultsafevuln authbrutediscovery exploitintrusivemalware dosfuzzerversion externalbroadcast

Gela honetako erantzun gakoak

Irekita dagoen arrazoia (-sS --reason)syn-ack

Script komandoak

sudo nmap -p 22 --script ssh2-enum-algos TARGET
sudo nmap -sS -n --script "http-date" TARGET
sudo nmap -sS -n --script "http-robots.txt" -p 80 TARGET
nmap --script "ftp*" TARGET
nmap --script=vuln TARGET

Izena http- da, ez https-. Beti jarri helburuko IP-a amaieran.
